# AudioCards

Applicazione desktop offline per convertire flashcard in percorsi audio MP3 di apprendimento e ripasso.

**Stato:** sorgenti e build Windows ancora da pubblicare e collaudare. Questo repository non contiene ancora una release utilizzabile.

La build portatile Windows includera' Python, Piper TTS, modelli vocali italiano e inglese e FFmpeg. Non scaricare eseguibili finche' non sono pubblicati e verificati.
